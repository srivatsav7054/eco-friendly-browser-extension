EcoCart – Browser Extension for Product Sustainability
EcoCart is a browser extension that scans e‑commerce product pages and displays a clean, side-panel sustainability report with a green score, estimated carbon footprint, and additional insights to help users make more environmentally friendly shopping decisions.

Features
- Opens a right-side eco panel on any supported product page to show sustainability details.
​- Extracts the product title from popular e‑commerce layouts (Amazon, Flipkart, etc.) using robust DOM selectors and fallbacks.
​- Sends the detected product name to the extension backend to fetch sustainability data such as green score, carbon footprint, and summary.
- Renders a white-themed, high-contrast UI with a slide‑in animation and a close button for a smooth UX.
- Provides a warning notice if the user tries to open the panel on a non‑product page.

How To Use
1. Download the project folder
2. Open the Extensions page in Chrome
3. Turn on Developer Mode
4. Load the extension
   - Click the button “Load unpacked”.
   - In the file dialog that opens, select the folder that contains the extension files, then click “Select folder”.
You should now see your extension appear in the list.
